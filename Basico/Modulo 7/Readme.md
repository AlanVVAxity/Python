# Módulo 07 — HTTP y consumo de APIs

Proyecto práctico del módulo 7 del nivel fundamental.

## Objetivo

Construir un cliente HTTP robusto que incluya:

- Solicitudes GET mediante `httpx`.
- Configuración de timeouts.
- Reintentos ante errores temporales.
- Manejo controlado de errores HTTP, conexión y timeout.
- Descarga de archivos mediante streaming.
- Pruebas automatizadas con pytest y pytest-httpx.

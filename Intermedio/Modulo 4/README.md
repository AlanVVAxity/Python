Proyecto práctico del módulo intermedio de concurrencia y rendimiento.

## Ejercicios incluidos

- Cliente HTTP síncrono.

- Comparación de tiempos de ejecución.
- Tarea intensiva de CPU ejecutada con múltiples procesos.
- Medición de rendimiento y perfilado.
